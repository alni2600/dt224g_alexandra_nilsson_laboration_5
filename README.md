**Laboration 5 i kursen Introduktion till webbutveckling med HTML, CSS och JavaScript, DT224G**

**Uppgiftsbeskrivning**
I denna laboration ska vi skapa funktionaliteten till en studentkortsgenerator.

Vi får färdiga HTML- och CSS-filer som utgör gränssnittet till applikationen samt en påbörjad JavaScript-fil. Min uppgift är att färdigställa JavaScript-koden så att användaren kan skapa studentkort utifrån information som matas in i ett formulär.

När ett studentkort skapas ska informationen även sparas i en historik med hjälp av webbläsarens localStorage.

**Applikationen ska kunna:**

1. läsa information från formuläret
2. kontrollera att obligatoriska fält är ifyllda
3. visa tydliga felmeddelanden om något saknas
4. generera ett studentkort med den angivna informationen
5. använda det typsnitt användaren valt
6. spara skapade studentkort i en historik
7. visa tidigare sparade studentkort
8. uppdatera historiken direkt när ett nytt studentkort skapas
9. rensa formuläret och eventuella felmeddelanden
10. radera hela historiken
